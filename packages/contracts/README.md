# @kolo/contracts

Versioned, runtime-validated payloads for device exchange and the server’s `/api/v2`:
signed event batches, receipts, pairing and encrypted file formats. Parsers bound
sizes, refuse future versions and mixed tenants, and detect repeated IDs. Signature
checks and applying data belong to `@kolo/core`.

See [exchange](../../docs/implementation/exchange.md) and the
[API reference](../../docs/reference/typescript-api.md).
