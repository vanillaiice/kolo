## Writing a post

Add `src/content/blog/en/<name>.mdx`, `src/content/blog/fr/<name>.mdx`, or both. The same
file name in both folders links the two languages; a post can also exist in only one.

- Headings start at `##`; the title is the page heading.
- Use regular Markdown links and lists.
- Add a video with `<Video src="…" poster="…" captions={{ en: "…" }} />`.
